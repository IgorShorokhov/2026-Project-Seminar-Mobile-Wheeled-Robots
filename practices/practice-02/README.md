# Практическая работа 2, вариант 18

В сцене находится площадка 12 × 12 м, робот TurtleBot3 Burger и два неподвижных препятствия в форме цифр «1» и «8». Робот появляется справа от цифр, направленным вдоль оси Y.

## Сборка и запуск

В терминале контейнера:

```bash
cd ~/practices_ws
colcon build --symlink-install
source install/setup.zsh
ros2 launch practice_02_webots spawn_robot.launch.py
```

## Движение по кругу

Во втором терминале контейнера нужно подключить пакет, чтобы выполнять последующие команды:

```bash
source ~/practices_ws/install/setup.zsh
```

Затем отправляйте команду скорости:

```bash
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/TwistStamped "{header: {frame_id: 'base_link'}, twist: {linear: {x: 0.2}, angular: {z: 0.05}}}"
```

Робот движется вперёд со скоростью 0,2 м/с и поворачивает против часовой стрелки со скоростью 0,05 рад/с. Этого достаточно, чтобы объехать цифры по кругу и вернуться на место. После полного круга остановите публикацию сочетанием `Ctrl+C`
